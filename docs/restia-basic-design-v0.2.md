# P-Tech Restia — 基本設計 v0.2 (ドラフト)
更新: 2026-10-13

## 1. 設計目的
FiveMの飲食店に日常的な遊びを追加し、待ち時間・暇な時間を減らす。一方で、学習しなければ働けない設計を避け、初心者のシンプル操作と希望者の高度な操作を共存させる。

設計原則:
1. 基本操作だけで仕事が完結し、組織が通常営業できる。
2. 複雑な工程への参加は任意で、成功に応じて店舗の原価・効率・品質などにプラスの価値が生まれる。
3. 高度なプレイを強制しない。シンプルプレイも赤字前提にしない。
4. 各機能はできる限り独立したFiveMリソースとして導入・更新可能にする。

## 2. プレイヤー体験
### 顧客
来店 → メニュー確認 → 注文 → 提供 →（店内専用料理の場合）着席・食事 → 満腹等の回復。
店内専用料理は原則インベントリアイテムを生成せず、注文ID・店舗ID・座席IDと紐づいた状態として扱う。

### 店員
受注 → 簡単調理または本格調理 → 提供 → 売上計上。
本格調理では食材選定、下処理、加熱、盛付等の段階的ミニゲームを導入する余地を残す。

### 店舗
店舗ごとに `serviceMode = 'staff' | 'auto'` を設定。
- staff: 店員のサーバー検証された提供操作を待つ。
- auto: 準備時間経過後に自動で提供する。
提供後の食事・回復処理は共通化する。
提供方式と調理難易度は独立した概念とする。

## 3. 料理モデル
- consumptionMode: `portable` または `dine_in`
- difficulty: `simple` および任意の `advanced`
- nutrition: hunger/thirst 等の回復設定（ステータスアダプター経由）
- price, baseIngredients, preparationSeconds, consumptionSeconds
- specialRecipe: 高度な調理や特別メニューの任意フラグ。持ち運び可否とは別の属性。

店内専用料理は店舗と指定座席で消費。食事時間や回復値は店舗/レシピ単位で上書きできる。初期バランス案として店内20～40秒・満腹度50～80%等を試験するが確定ではない。

## 4. 経済とやり込み
- シンプル調理でも通常の利益が出る価格・原価を確保。
- 高度な調理により食材消費効率、品質、注文処理効率、店舗評価などを改善できる。
- 利益差は初期案であり、時給換算、難易度、失敗率、プレイヤー離脱への影響をテストするまで確定しない。
- 追加報酬の計算はサーバー側で実行し、クライアントの成功報告だけを信用しない。
- 顧客に難しい注文操作を強制しない。

## 5. モジュールの責務
| Module | 機能 | MVP |
|---|---|---|
| ptech_restia_dining | 座席・店内専用料理・食事状態・回復 | 最優先 |
| ptech_restia_order | 注文受付・キッチン通知 | 後続 |
| ptech_restia_cooking | 簡単調理・高度調理・調理結果 | 後続 |
| ptech_restia_inventory | 食材在庫・仕入れ | 後続 |
| ptech_restia_register | 決済・会計 | 後続 |
| ptech_restia_management | 店舗運営・権限・設定 | 後続 |

dining MVPには最小限の注文・決済アダプターを含め、後にorder/registerとの任意連携へ切り替えられるようにする。共通Coreは本当に複数リソース間で必要となった場合のみ導入する。

## 6. 食事状態機械
`ordered → preparing → served → eating → completed`
失敗・キャンセル・期限切れ・切断時は専用の終了状態へ移動する。決済はトランザクションIDを関連付け、払い戻しポリシーは後で決定する。

サーバーが正当性を検証する対象:
- 店舗・座席の存在と範囲、プレイヤーの距離
- 注文の所有者、スタッフジョブ・役職
- 重複提供、同時利用、二重回復
- 再接続・リソース再起動時の不整合
- キャンセル・切断時の料金や在庫の確定タイミング

## 7. 対応技術
まずQbox向けのアダプターを検討し、QBCore/ESX等は任意拡張とする。Qbox公式の `qbx_core:GetMetadata` / `SetMetadata` 等がステータス連携候補。既存ステータス・医療リソースと競合しないようにアダプター方式を採る。
参考: https://docs.qbox.re/resources/qbx_core/exports/server
